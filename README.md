# User Performance Analysis Using SQL

## Project Overview
This project analyzes user submission data using SQL to understand performance, submission patterns, and weekly rankings.

## Objectives
- Calculate total submissions and points earned by each user.
- Analyze daily average points for users.
- Identify the top 3 users with the most correct submissions each day.
- Find the top 5 users with the highest number of incorrect submissions.
- Identify the top 10 performers for each week.

## SQL Concepts Used
- Aggregate functions: `SUM()`, `COUNT()`, `AVG()`
- Conditional logic: `CASE WHEN`
- Common Table Expressions (CTEs)
- Window functions: `DENSE_RANK()`
- Data grouping and sorting: `GROUP BY`, `ORDER BY`
- Date functions: `DATE()`, `WEEK()`

## Tools
- MySQL
- SQL

## Project File
`User_Performance_Analysis.sql` — contains the SQL queries and their solutions.

## Key Learnings
This project demonstrates how SQL can be used to aggregate user activity, identify performance trends, and rank users within daily and weekly groups.
